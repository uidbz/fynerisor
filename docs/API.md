# fynerisor API reference

Generated by `fynerisor docs --markdown` from the compiled attribute
registries (issue #38) — this file is the authoritative list of script-visible
types and their attributes. Do not edit by hand; CI fails if it drifts from
the code.

Property entries are read by name (`t.Text`); callable entries are invoked
with parentheses (`t.SetText(x)`).

## app

- `name` — Name of the embedding application
- `version` — Version of the embedding application (if set via SetAppVersion)
- `Quit()` — Quit the application (app.Quit())

- `DroppedPaths`
- `Close()`
- `SetContent(arg1)` — Set the window content. A run that has been stopped or replaced must not swap the content of the run that replaced it.
- `SetStdout(arg1)` — Route the run's stdout to a Log widget, writer object, or closure; nil restores the default. A Log widget is the preferred sink: an io.Writer fed on the VM goroutine, never re-entering the VM (#24).
- `CaptureStdout(arg1)` — Deprecated alias of SetStdout.
- `OnDropped(arg1)`
- `SetStatus(arg1)` — Set the run status shown in the title bar. A stopped or replaced run must not overwrite the status of the run that replaced it (#16, #52).
- `Resize(arg1, arg2)`
- `AddShortcut(arg1, arg2)` — Bind a shortcut string (e.g. "Ctrl+S") to a callback; events queue on the script's VM goroutine. Tracked for removal when the run ends.
- `RemoveShortcut(arg1)` — Remove a shortcut previously added with AddShortcut.
- `SetMainMenu(arg1)` — Set the window's main menu. The owning run is tracked so the next run removes the old menu and its dead item callbacks.
- `Size` — Current window size as a map with width and height keys.
