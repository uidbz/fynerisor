# Images Directory

Place your image files (PNG, JPG, JPEG, GIF) in this directory.

The example will automatically scan for image files and display them in the table.

## Supported Formats
- PNG (.png)
- JPEG (.jpg, .jpeg)
- GIF (.gif)

## Example
Add some sample images:
```bash
cp ~/Pictures/*.jpg pics/
cp ~/Pictures/*.png pics/
```

Or download some sample images:
```bash
wget -O pics/sample1.jpg https://picsum.photos/200/150
wget -O pics/sample2.jpg https://picsum.photos/200/150
wget -O pics/sample3.jpg https://picsum.photos/200/150
```
